# voice-sdk

`voice-sdk` is the public npm entry point for TVIC: a local-first,
provider-neutral runtime for building voice agents with bring-your-own
telephony, speech, model, and synthesis providers.

This `0.0.x` package is an early preview that reserves the stable package name
while the high-level `createVoiceAgent` API is being completed. It does not yet
expose the executable runtime and should not be used in production.

Development happens in the [TVIC repository](https://github.com/Kkartik14/TVIC).
